# Arrays in JavaScript

This folder contains my JavaScript solutions to Data Structures and Algorithms (DSA) problems related to arrays.

## Topics Covered

- Array Traversal
- Insertion and Deletion
- Linear Search and Binary Search
- Reverse Array
- Second Largest Element
- Check if Array Is Sorted
- Remove Duplicates
- Move Zeroes
- Missing Number
- Find Disappeared Numbers
- Rotate Array
- Contains Duplicate
- Number of Good Pairs
- Maximum Consecutive Ones
- Two Sum
- Merge Sorted Array
- Maximum Subarray (Kadane's Algorithm)
- Unique Number of Occurrences

## Learning Approach

I practise each problem by understanding the logic, writing JavaScript code, performing dry runs, and improving my solutions.

## Goal

To strengthen my problem-solving skills and build a strong foundation in Data Structures and Algorithms for software development interviews.
